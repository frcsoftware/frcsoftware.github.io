Java uses operators to change or compare the values of variables.
There four different types of operators are:

- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Logical Operators

Assignment operators are similar to arithmetic operators.
The main difference is that assignment operators are the shorthand version.
Using assignment operators can help make code easier to read.
It prevents having to write the variable name twice which can also be helpful in preventing code errors.

<Aside type="note">
`==` and `!=` can not be used to compare the values of `String`s.

Though it's not used, more information can be found [here.](https://www.w3schools.com/java/ref_string_equals.asp)

More information can be found [here](https://www.w3schools.com/java/ref_string_compareto.asp).

</Aside>

### Pay attention to equals signs!

When using comparison operators, make sure to use a double equal sign `==` instead of a single equal `=`.
Unlike in math, a single equal is assignment.

In the example below, the print statement would not run.
You would get an error message about how the left hand side of an assignment must be a variable.
{/* rli:ignore */}

```java
    System.out.println(6 = 8);
```

Adding the double equal sign, fixes the error because the compiler will read this as comparing the value on the left to the value on the right.
This will print out `false` because 6 is not equal to 8.
{/* rli:ignore */}

```java
    System.out.println(6 == 8);
```

## Logical Operators

Logical operators help a program make decisions by using true or false statements.
They are also used in conditionals.

<Aside type="note">
    Logical operators also follow the order of operations (known as PEMDAS) and
    parentheses can be used to change this order.
</Aside>

<table class="Comparison Operators">
    <thead>
        <tr>
            <th>Operator</th>
            <th>Description</th>
            <th>Example</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>`&&`</td>
            <td>And: true if both statements are true</td>
            <td>`true && true // this is true`</td>
        </tr>
        <tr>
            <td>`||`</td>
            <td>Or: true if at least one statement is true</td>
            <td>`true || false // this is true`</td>
        </tr>
        <tr>
            <td>`!`</td>
            <td>Not: reverses. If true, then false. If false, then true </td>
            <td> `!true // this changes to false`</td>
        </tr>
    </tbody>
</table>
